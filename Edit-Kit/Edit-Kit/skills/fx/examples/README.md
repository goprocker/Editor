# Examples

Three finished compositions from the kit's test edits. They are the reference for layout, timing and code style.
Media (footage, cutouts, logos, fonts) is not included: swap in your own and re-time to your WORDS.

| File | Preset | Shows |
|---|---|---|
| real-estate-reel_9x16.html | Real Estate, Agent Story | word behind the subject (cutout), strike-through, punch-ins, checklist chips, red X chip, status card, target ring + avatars, kinetic captions with scrim |
| saas-promo_16x9.html | Dark Neon SaaS | prompt bar typing + cursor click, 3D dashboard tilt-in, rows lighting on words, zoom-through, progress steps + %, logo orbit, wordmark sheen, per-letter tracking |
| youtube-talking-head_16x9.html | Clean Talking Head | base zoom crop, punch-ins, logo patch, glass side cards, star rating, graph draw-on, profile counter, checklist chips, hearts, bar chart, grain + vignette |

Each has a matching `*.cues.json` (SFX cue sheet for /sound).
These were written before the shared runtime: helpers are inline. New edits should use motionkit.js.
